# 🟢 Básico 05 — Nombre y tipo de variables

## 🧩 Problema

Vas a diseñar la ficha de registro de un paciente de **MediSalud**. Antes de escribir
código, necesitás decidir, para cada dato, **cómo se llamará**, **de qué tipo será** y
si es una **variable** o una **constante**.

## 💻 Código o contexto de partida

Completá la tabla para los ocho datos:

| N.º | Dato | Ejemplo de valor | Identificador | Tipo | ¿Variable o constante? |
|---|---|---|---|---|---|
| 1 | Nombre del paciente | `Ana Torres` | | | |
| 2 | Edad del paciente | `34` | | | |
| 3 | Número de historia clínica | `9876543210` | | | |
| 4 | Peso en kilogramos | `62.5` | | | |
| 5 | Grupo sanguíneo (una sola letra) | `O` | | | |
| 6 | ¿Es afiliado? (sí o no) | `sí` | | | |
| 7 | Nombre de la clínica (nunca cambia) | `MediSalud` | | | |
| 8 | Valor de la consulta (fijo para todos) | `85000.0` | | | |

Para el tipo, usá `int`, `long`, `double`, `char`, `boolean` o `String` (texto).

## 📏 Criterios de evaluación de la solución

- Los identificadores siguen las reglas (empiezan con letra, sin espacios, sin
  tildes) y las convenciones: `camelCase` para las variables y
  `MAYUSCULAS_CON_GUION_BAJO` para las constantes.
- Cada tipo es adecuado al dato (en particular: el número de historia necesita `long`
  porque no cabe en un `int`, y el grupo sanguíneo es un `char`).
- Los datos que no cambian (7 y 8) se marcan como constantes, y los demás como
  variables.

## 🚧 Restricciones

- No hace falta escribir código: completá solo la tabla.
- Los nombres deben estar en español y sin tildes ni `ñ`.
